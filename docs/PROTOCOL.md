# 갤럭시 ↔ 애플워치 BLE 규약

갤럭시가 BLE 주변기기(GATT 서버), 워치가 중앙(GATT 클라이언트)이다.

| 이름 | UUID | 방향 | 속성 |
|---|---|---|---|
| 서비스 | `5F1D0001-8C3B-4C2A-9A1E-2B7F6D3A0C11` | | |
| NOTIFY | `5F1D0002-…` | 갤럭시 → 워치 | notify (암호화 필요) |
| CONTROL | `5F1D0003-…` | 워치 → 갤럭시 | write / write without response (암호화 필요) |

NOTIFY 와 CONTROL 은 암호화된 연결(본딩)이 필요하다. 처음 접속할 때 페어링 확인이 한 번 뜨고,
그 뒤에는 본딩이 된 기기만 알림을 받을 수 있다. 앱에는 `INTERNET` 권한이 없다.

## 프레임

BLE 한 번에 보낼 수 있는 크기(MTU - 3)가 작아서 JSON 한 건을 프레임으로 쪼갠다.

```
byte 0   msgId  (0~255, 건마다 1씩 증가하고 255 다음은 0)
byte 1   bit7 = 마지막 프레임, bit0~6 = 순번(0부터)
byte 2…  UTF-8 JSON 의 조각
```

받는 쪽은 순번이 0이면 새 건으로 시작하고, 순번이 어긋나면 그 건을 버린다.
한 건은 최대 128프레임이다.

## JSON 종류

```json
{"v":1,"t":"hello","app":"watch-bridge-galaxy"}
{"v":1,"t":"hb","n":12,"ts":1732250000000}
{"v":1,"t":"msg","app":"kakao","from":"홍길동","room":"","text":"내용","ts":1732250000000}
```

- `hello`: 워치가 구독하면 갤럭시가 보낸다. 워치도 CONTROL 로 `hello` 를 보낸다.
- `hb`: 15초마다. 백그라운드 생존 시험용이다. 워치 화면의 "마지막 하트비트"로 본다.
- `msg`: 카톡 알림 한 건. `from` 40자, `room` 40자, `text` 200자까지 자른다.
